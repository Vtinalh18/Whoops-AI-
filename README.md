# Whoops AI!

Hub personal para crear prompts e imágenes con varias IAs en un solo lugar: Gemini, ChatGPT, Higgsfield, Pomelli y Firefly.

**App:** https://vtinalh18.github.io/Whoops-AI-/

- Funciona en computador y tablet (Chrome, Edge o Safari).
- La clave de Gemini y todos los datos (clientes, imágenes, recetas) se guardan solo en el navegador de cada dispositivo; no están en este repositorio.
- Para mover tus datos entre dispositivos usa **Ajustes → Descargar respaldo / Restaurar respaldo**.
