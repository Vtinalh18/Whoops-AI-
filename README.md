# Whoops AI!

Hub personal para crear prompts e imágenes con varias IAs en un solo lugar (Gemini, ChatGPT, Higgsfield, Pomelli, Firefly y Freepik, más Claude para pulir prompts), con research, conceptos de campaña y aprendizaje.

**App:** https://vtinalh18.github.io/Whoops-AI-/

- **General:** Crear, Generar y comparar, Biblioteca, Edición rápida.
- **Estrategia:** Mapa de campaña, Research (swipe file con análisis), Conceptos (fichas con chat y versiones).
- **Aprender:** Frameworks, Competidores, Pregúntale a la IA.

La clave de Gemini y todos los datos se guardan solo en el navegador de cada dispositivo; no están en este repositorio. Para mover tus datos entre dispositivos usa **Ajustes → Descargar respaldo / Restaurar respaldo**.
